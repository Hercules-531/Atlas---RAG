# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated through the approved plan: local FastAPI, React/Vite, SQLite, persistent Chroma, local EmbeddingGemma 2.
## Users
People asking questions about their own mixed documents; hackathon judges evaluating utility, efficiency, safety, and proof.
## Product Purpose
Minimum necessary, with proof. Retrieve locally, withhold unrelated data, tokenize necessary sensitive values, ask consent, and inspect the exact cloud disclosure.
## Constraints
Single central ask bar; top-left upload; top-right privacy; collapsible history; bottom answer drawer. All persistent user data stays local. Cloud inference goes through Prune; zero authorized paid spend. No guaranteed-private claim.
## Brand Commitments
Atlas; local public-domain Starry Night background with restrained motion; minimal readable controls. The approved plan fixes composition; implement directly from that brief.
## Evidence
Synthetic datasets and measured results only. No existing model accuracy or performance results.
## Accessibility
Keyboard operable, responsive, reduced-motion support, visible focus and readable contrast.
